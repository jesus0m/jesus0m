### 💡 My Contributions

I contributed gameplay enhancements, visual improvements and localization updates to an open-source Nintendo 3DS project.

The work includes a configurable day/night system inspired by Pokémon HeartGold and SoulSilver, dynamic lighting, time-based gameplay mechanics and compatibility improvements.

#### 🌗 Dynamic Day & Night System

- Configurable day/night cycle inspired by Pokémon HGSS.
- Smooth transitions between different times of day.
- Dynamic sunlight and moving solar shadows.
- Warm nighttime illumination for voxel buildings.
- Window lighting and streetlamp effects.
- Ambient moonlight and nighttime visual enhancements.

#### ⏰ Advanced Game Clock

- Configurable time acceleration: `1x`, `6x`, `12x`, `24x`, `60x`, `120x`.
- Persistent clock across game sessions.
- Clock-driven berry growth and regrowth.
- Integration with the Nintendo 3DS real-time clock.

#### 🎮 Gameplay Enhancements

- Optional time-based wild Pokémon encounters.
- Different encounter pools depending on the time of day.
- Clock visualization on the bottom screen.
- Improvements to the Pokédex interface.
- Compatibility with existing save files.

#### 🌍 Localization & Compatibility

- Spanish translation enhancements.
- English and Spanish build compatibility.
- Improved localization and user-interface behavior.
- Native regression testing and build validation.
